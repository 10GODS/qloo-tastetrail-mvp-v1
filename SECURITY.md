# Security

TasteTrail reads the Qloo credential from an environment variable only. Never
put a key in source, a notebook, a browser form, a screenshot, a commit, or a
public issue. If a key is exposed, revoke or rotate it through the Qloo support
channel before continuing.

The application sends only the user's location and interest phrases to Qloo.
Do not enter names, email addresses, device identifiers, or other personal
data. Qloo results describe aggregate audience affinity and should not be
presented as deterministic predictions about an individual.

Report suspected credential exposure privately to the project owner rather than
opening a public issue.
