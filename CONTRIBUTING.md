# Contributing

1. Create a virtual environment if desired; the MVP uses only the Python
   standard library.
2. Run `python -m unittest discover -s tests -v` before a change.
3. Keep credentials, personal data, and raw Qloo responses out of commits and
   logs.
4. Preserve attribution for Qloo and any additional assets or datasets.
5. Describe live API, hosting, and demo validation separately from offline
   tests.
